For players: download **nikke-trace-v3.2.zip**, extract it and run **NikkeTrace.cmd**. The ZIP contains one file. English and French are available.

This update adds a targeted check for the known persistence DLL inside **Steam WebHelper** and **RuneApps Alt1** when those applications are running in your current Windows session.

- If Steam or Alt1 is absent or closed, it is silently skipped. No installation warning, error or extra question is shown.
- If a suspicious file is found in either application, the result names Steam or Alt1 in plain language. Process names, identifiers and file paths remain in the detailed report.
- A genuine read failure remains an incomplete check; it is never reported as proof of infection or a successful clean result.

The cleanup scope, consent prompts and restart requirement are unchanged. Steam and Alt1 are not closed, blocked, modified or uninstalled by this check.

**Validation:** 243 automated checks on inert fixtures and mocked operations, including absent/closed applications, clean and suspicious loaded modules, other Windows sessions and module-access failures. Release automation reruns the tests on Windows before publishing the archive.

NikkeTrace checks known traces, not the entire PC for malware. Cleanup cannot undo possible credential theft: secure your accounts from a clean device, even if no traces are found.
